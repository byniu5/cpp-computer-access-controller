### MinGW compiler notes
<p>
To compile the code there is necessary to install MinGW compiler.
I downloaded MSYS2 that has some other compilers, but I need only MinGW that contains gcc and g++.
For C code mainly but with additional C++ support. and g++ for full base C++ support.
<p>
<p>
Base compiler that run automatically on windows is ucrt64. Add it to system PATH.
C:\msys64\ucrt64\bin
<p>
<p>
Just after that, I got automatic compilation of my project when I run it.
</p>
